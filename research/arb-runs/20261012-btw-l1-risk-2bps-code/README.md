# BTW 单腿 2bp 毛止盈 / 毛止损回放

沿用 2026-10-01 UTC Bybit / Bitget BTW 原始逐笔成交与增量盘口、当时可用的20日波动率Top10准入及资金费证据，仅离线模拟。

按用户最终要求，止盈和止损均不将手续费纳入触发判断。基准沿用原策略的多头腿开仓名义金额：`N = 剩余BTW数量 × 多头原始开仓价`。在有效一档报价下，双腿预计毛价格损益 `G = q × (多头退出买一价 − 多头开仓价 + 空头开仓价 − 空头退出卖一价)`；`G >= N × 2 / 10000` 触发止盈，`G <= -N × 2 / 10000` 触发止损。每笔成交手续费仍为3bp，正常从账户与最终净损益中扣除，止盈标签不等于扣费后盈利。

买入使用卖一、卖出使用买一；每档显示量25%为可消耗预算，同一档未增加显示量不补预算。两所各1000 USDT，单腿至多250 USDT、1倍、双腿同币数。入场净门槛5bp及原退出/资金费缓冲不变，原始入场价差需达21bp。60秒持仓退出、30秒平仓后冷却、累计账户净亏损10 USDT后停新仓、资金费与日末保护保持原规则。先触发的退出原因保留，分批退出不撤销；2bp是触发线，不保证最终毛损失或净损失不超线。

一档预算不足时，以可执行片段的价格估算剩余持仓毛/净损益，并记录`partial_depth_position_pnl_proxy`；真正成交数量仍受预算约束。触发事件保存数量、单腿名义金额、毛/净估计、费用、两条阈值及价格供独立核对。无新鲜可执行片段时等待，不能借用第二档。

`paper_snapshot.py`是原共享PaperSession的本地版本，实际差异限于导入、风控字段、毛/净损益分解及止盈止损比较。`risk_policy.py`用`stop_loss_bps`替换旧固定`stop_loss_usdt`。旧执行源码与旧结果保留，`provenance.json`记录来源哈希，正式运行元数据固定本版及共享依赖哈希。

两个bp参数独立可配置；本次验收脚本固定核对用户指定的2/2bp。`--benchmark-batches`只检查入口，不是完整策略结果。测试覆盖阈值两侧与等号、方向互换、手续费不触发止损、毛止盈但净亏、分批退出、原保护优先级、一档预算、回滚及原始消息适配。完成后进行账务/导出、原始一档成交及风险触发三项独立验收，再生成报告。

本轮仍假设双腿同步理想成交，未建模网络延迟、单腿失败、部分成交异步风险或标记价格强平。历史合约数量约束采用10月9日快照情景，尚非已证实的10月1日规则。
