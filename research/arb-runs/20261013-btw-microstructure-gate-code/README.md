## 数据和解释

- `extract_book_events.py` 从原始公开L2档案生成有序事件：快照、断线、增量价位行数。增量行数不是逐订单新挂/撤单数，快照不计入强度。
- `build_features.py` 按原生决策纳秒计算每所 `12*N5/N60` 的盘口与成交速率比，按各自数据源恢复状态预热60秒。缺失覆盖有独立对照，不当成低活跃。
- 过去5/60秒窗口用于统计，不要求本次价差持续5/60秒。保留的门槛为1倍和2倍，均须两所达标。
- 原冻结gate文件保留全部14位，禁止直接删列并复用旧位序。历史代码仍能重现撤销组，不意味着撤销组继续有效。
- `perfect_taker`/`.cpp` 和原共享reader与前轮字节一致：0额外延迟、双腿全额对手一档，退出量允许超过显示深度。只做理想回放。

原实验顺序为协议冻结 → 原始事件抽取 → 原生特征/独立核验 → `prepare.py` → 8月/9月回放与审计 → `freeze_selection.py` → 10月诊断回放与审计。

`report-enrichment.json` 绑定自动报告初稿与补充具体解释后的最终报告。

输出脚本拒绝覆盖已有成果。要复现必须使用新输出目录，不对现有目录重新运行。
